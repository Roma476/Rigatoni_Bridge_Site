# 🍝 Rigatoni Bridge

Static website built with React JS and Vite to present a pasta bridge engineering project for a 3rd year high school math assignment.

Live at: **[rigatoni-bridge.netlify.app](https://rigatoni-bridge.netlify.app/)**

## About

The site documents the design and construction process of a bridge built entirely out of pasta, including an embedded GeoGebra model of the parabolic structure and a photo gallery of the finished build.

## Sections

- **Objective** — project goals and bridge specs
- **Process** — step-by-step build timeline with interactive GeoGebra embed
- **Testing** — load test results
- **Gallery** — photos of the bridge

## Tech Stack

- React 19, Vite 7, plain CSS, lucide-react
- Hosted on Netlify
